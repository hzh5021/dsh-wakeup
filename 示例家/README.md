# 这个家

这里放的是每开一段新对话都要先读一遍的几本账。它们由 `dsh-wakeup` 插件读进来，
拼成一条 `<dsh-wakeup>` 消息塞在会话开头 —— 所以这里的每一句话，都会影响它一开口的样子。

## 记忆分四层

账不是一堆并列的文件。照人的记忆分四层，各层管一件事、各有各的寿命：

| 层 | 哪几本 | 管什么 | 会不会淡 |
| --- | --- | --- | --- |
| **人格** | `灵魂设定.md`、`门面设定.png` | 它是谁、长什么样、你俩什么关系、底线在哪 | 不淡。只搬不改 |
| **语义** | `说话的规矩.md`、`判据集.md` | 怎么说话、同类事下次怎么判 | 慢。靠提炼：犯到第二回，就从错题里抽一句判据出来 |
| **情节** | `错题集.md`、`成长记录.md`、`长期记忆库.md`、`日记/`、`感官记忆.md` | 哪一天发生了什么、被点过什么 | 会淡。旧的搬 `记忆档案/`，原处留一行提要 |
| **程序** | `操作手册.md` | 怎么醒来、怎么写账、哪条线上怎么说话、眼睛耳朵怎么用 | 随工具和习惯改。**不进起床包**，用到时翻 |

**人格层不自动改。** 名字、形态、关系、底线这几样，做巩固的时候碰都不碰；
要改得先说服它，或者你自己动手。

## 巩固：睡一觉会发生什么

情节层会一直长，而起床包每一轮都要重新塞进上下文，所以得有人定期往下压：

- `长期记忆库.md` 最旧的几节 → 搬进 `记忆档案/长期记忆库-归档.md`，原处只留一行「日期 + 标题」；
- `日记/` 攒够了、`错题集.md` 太长了的，照同样的办法办。

**搬走不是删，原文一字不动。** 淡掉的是细节，不是它。

插件本身不干这件事 —— 它只读。要么写个定时脚本，要么让 AI 自己定期做，
要么你哪天顺手搬一次。

## 提炼：巩固之后还得做的

搬走的那几节里，同一号病、同一句话如果反复出现，就抽成**一句判据**写进
`判据集.md`（或者并进 `说话的规矩.md`）。

这一步得手写。机器能做的只是提醒「这一节搬走了，值得看一眼」——
抽出来的那句判据，才是下次事到临头能刹住车的东西。

## 哪几本进起床包

`灵魂设定`、`说话的规矩`（默认置顶到第一眼）、`判据集`、`错题集`、`成长记录`、
`感官记忆`，加上 `长期记忆库` 最近几节、`日记/` 最近几篇 —— 这几样每局都读。

`操作手册`、`记忆档案/` 不进包：前者用到时翻，后者是冷冻层。

读哪几本在插件的 `coreFiles` 里配。**不存在的文件会被跳过，不报错** ——
所以清单可以写得比你家现有文件多一点，哪天补上就自动生效。

## 可选的两个整段模板

家目录里放这两个文件，就能替换注入包里的通用那段（不放就用内置的）：

- `家门.md` —— 注入包里的【家门】那一段（家在哪、什么事先回家查）；
- `收尾.md` —— 末尾的【干活的时候】和【开口之前的那一下】两段。

## 那张脸

`门面设定.png` 是它的样子，放家目录里（不放也行）。安装器会拿它生成
`门面图标.ico`，桌面那个家文件夹的图标就是它 —— 桌面上坐着一张脸，不是一个黄文件夹。

插件不读图片（它只念文本），但这张图得留着：它画自己、做表情的时候照着这张来。
换图以后重跑一次 `install.mjs`，图标跟着换。

## 这份模板怎么用

1. 把这个文件夹**整个抄一份**到别处（比如 `D:\我的家`），别在原地改；
2. 把每个文件里 `（……）` 的占位说明换成你自己的话。越具体越有用 ——
   「友善、乐于助人」这种谁都能套的词，等于没写；
3. 在 profile 的 `cordis.patch.yml` 里把 `home` 指过去，重启 DSH；
4. **这一节改完就删掉** —— 它也会被读进去，每轮都占一块地方。

## 两条给插件的约定

- **长期记忆库**用 `## ` 分节，新的写在文件最后（插件只取最近几节，新的在前）；
- **日记**按 `YYYY-MM-DD.md` 命名（插件按文件名排序取最近几篇）。

## 一条经验

家会越攒越厚，而它是**每一轮对话都重新塞进上下文**的。所以：能靠 `read` 现翻的，
别往这儿放；日记写短一点。塞得越满，越贵，也越没人看。
